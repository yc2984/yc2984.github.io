This blog has no newsletter. It publishes an RSS feed: a small file that lists
every post and is rewritten the moment a new one goes live. A feed reader checks
that file for you and shows new posts next to everything else you follow.

To subscribe, copy this address into your reader:

```
https://yc2984.github.io/index.xml
```

Most readers also accept the site address on its own. Paste
`https://yc2984.github.io/` and they find the feed themselves.

If you open the feed address in a browser you will see raw XML. That is normal.
The file is written for the reader app, not for a person.

No reader yet? Any of these works:

- [NetNewsWire](https://netnewswire.com/), Mac and iPhone, free and open source
- [Feedly](https://feedly.com/), web and mobile
- [Inoreader](https://www.inoreader.com/), web and mobile
- [Reeder](https://reederapp.com/), Mac and iPhone

Comments live in [GitHub Discussions](https://github.com/yc2984/yc2984.github.io/discussions),
so following the repository there is the other way to hear about a new post.
